## ✨ Features

- 🔍 Quick Search — find recipes using keywords (ingredients, dish names).  
- 📸 Recipe Details — View image, ingredient list, and a link to the full cooking instructions.  
- 🥗 Nutrition Info — Displays detailed content of proteins, fats, and carbohydrates (macros) for each recipe.  
- ⏱️ Yield — Information on the number of servings (Yield).

## 🚀 Getting Started

### 1️⃣ Clone repository
```bash
git clone <YOUR_REPOSITORY_URL>
cd recipe-search-app
```

### 2️⃣ Install dependencies

npm install
#### or
yarn install

### 3️⃣ Add API keys (create .env file)
```env
REACT_APP_EDAMAM_ID=YOUR_APP_ID
REACT_APP_EDAMAM_KEY=YOUR_APP_KEY
```

### 4️⃣ Run the app
npm start
#### or
yarn start

The app will open at:
👉 http://localhost:3000
